缺失不等于零

固定 notebook 的部分绘图路径中，safe_apply 将 NaN 转为 0；Tahoe 数据读取处的注释还称 scGPT 缺少一个细胞系。这是对 notebook 代码的观察，不是对历史文件完整性的独立证明，也不确定具体缺失情境。

  • 共同评测须区分未运行、缺失输入、评分失败和指标未定义，记录原因；非有限值不得静默替换成有效零分。
  • 预先冻结各指标的有效性判定和汇总规则，分别报告每个模型、情境的有效数及缺失数；正式横向比较只使用共同且有效的集合，并明确该集合和分母。
  • 某模型缺少细胞系时应标记缺失，不以零或其他细胞系填补，也不能声称其参与了该情境的同协议比较。

共同集合筛选不能隐藏失败或改变预注册问题；按预定规则筛选指标时仍须保留原测试集合与排除清单。若改变训练、验证或测试划分，或改变共同基因轴，须按新的预注册方案重跑全部对照。真实同细胞数据、共享基础模型和泄漏审计的前置条件仍按 v1 执行。
