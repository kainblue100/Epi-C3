官方默认填充可能产生有限分数

在 cell-eval 0.8.2 中，DESpearmanLFC 先取真实 DE 表中 FDR 小于 0.05 的基因，再按靶点与基因左连接预测表；预测 LFC 因缺行或为空而得到的 null 会填为 0。这个填充值不证明预测过该基因。

PR 实现以真实 FDR 小于 0.05 建立标签，左连接预测表，并将缺失或为 null 的预测 FDR 填为 1，再以负对数排序计算 average_precision_score。真实标签为 null 的行会被移除。这里的 PR 数值是该实现返回的平均精度，不应未经核验称为梯形积分面积。

这些是固定版本的 fill_null 行为；不能假定它也会处理 IEEE NaN、无穷值或其他无效输入。评分前仍需分别检查缺行、空值和非有限值。

PR 平均精度基因 a、b、c 真实 FDR 为 [0.01, 0.01, 0.1]；预测仅有 a=0.01、c=0.1，缺少 b。填充后预测 FDR 为 [0.01, 1, 0.1]，排序为 a、c、b。5/6

两个分数都是有限的，但预测表都缺少基因 b。它们只说明默认指标的缺键行为，不能视为完整预测、真实测量或模型表现。

候选的评分前门槛

  • 冻结应有键：在评分前固定共同测试情境、每个情境的有序评测基因轴、注释和靶点映射，以及 DE 方法、对照和 FDR 规则。对每个情境建立应有基因键；若各情境轴相同，即为情境与基因的笛卡尔积。未测量和预先排除项要单独登记，不能根据某个模型实际输出事后缩小集合。
  • 逐表核对：对真实表和每个模型的预测表分别检查应有键、缺键、多余键及重复键，并检查所需 LFC、FDR 的空值、非有限值和 FDR 范围；核对真实与预测表之间的键差异。相同情境须使用相同的预定基因集合和规则。
  • 保留证据：按模型和情境报告应有、有效、缺失、多余、重复和无效值的数量及处理状态；可追溯清单须符合数据授权，公开内容不包含原始单细胞身份。非有限或未定义的指标按 v2 记录，不能静默改成零。
  • 区分原值与资格：保留官方返回的原始数值及版本，不把官方填入的 0 或 1 当作真实测量。缺键、重复键或无效值须标记并按预注册规则处理；未经解决的情境不得作为键完整的同协议正式比较。为审计保留的官方分数须与完整性状态并列，而非隐去问题。

若更改共同基因轴或数据划分，须在新的预注册方案上重跑全部模型和对照，不能沿用旧试验分数直接混排。不能通过补零、自动丢行或重新定义应有集合掩盖缺失。
