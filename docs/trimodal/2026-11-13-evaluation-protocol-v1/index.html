论文 PDS 与 cell-eval L1，不是同一个默认分数。

为未来严格同细胞 RNA / ATAC / 单细胞 Hi-C 扰动预测预留的共同评测补充；适用于共同划分上的所有模型和对照，不把既有试验分数直接混排。

候选协议，不是模型成绩或已完成的预注册。 共享基础模型、合格训练来源和隔离审计尚未满足要求；本页不报告预测结果，也不表示已经运行官方评测。

分开报告两个指标

在一个冻结的评测情境内，令 T 为相同候选集合中非对照扰动的数量，P_i 为预测扰动 i 的伪 bulk 表达，Y_j 为真实扰动 j 的伪 bulk 表达。论文方法使用扰动伪 bulk 的距离，并按严格小于计算排名：

r_i = #{ j : D(P_i, Y_j) < D(P_i, Y_i) }
paper_PDS_i = 1 - 2r_i/T

候选方案拟在冻结的共同基因轴上使用 L1 距离；正式称为论文口径前，仍须核对论文的预处理、基因选择与距离细节。平局不计入严格小于的 r_i。记录逐扰动分数、排名、距离平局数和 T，并预先冻结跨条件与跨情境的汇总权重。

两个结果必须分别标注。对官方默认字段直接计算 2 × cell-eval - 1 只改变尺度，不会消除输入、基因排除、对照或平局规则的差异。只有两者实际排名一致时，该换算才等于论文公式；距离函数、输入、基因轴和排除规则一致且没有平局是充分条件，不应未经核验假定成立。

0.8.2 的 L1 实现会忽略 embed_key 并使用表达轴；平局的排序位置取决于 argsort 和输入顺序，不等于论文的严格小于规则。保存 NumPy 版本、候选顺序和每个条件的平局数；近似平局的敏感性分析须单独标注，不能悄悄改变主指标。

基因轴、靶点与对照必须先冻结

  • 共同基因轴：冻结物种、基因注释版本、预处理、特征顺序与轴哈希；真实和各模型预测必须使用同一有序轴。未测量基因不能静默补零。
  • 靶点映射：预先审计 Ensembl ID、版本号和 gene symbol 的对应关系，以及多靶点或药物标签。记录可唯一映射、歧义、缺失和实际精确匹配的情况；不得把字符串未命中的靶基因声称为已排除。歧义或缺失必须按共同的预注册规则处理，不得逐模型静默删条件。
  • 对照：冻结真实与预测对照的来源、情境、处理方式和使用范围。论文伪 bulk 指标与 cell-eval 的各自对照 delta 分别计算；对照均值不同可能改变排序。缺少必需对照时应停止该项评分，而不是伪造或替换对照。
  • 可比性：固定相同的候选扰动集合、数据划分、预测细胞数和聚合方式，审计实际 cell-eval 输入及其预处理。若更改基因轴或划分，所有对照和模型都须在新的预注册划分上重跑，不沿用旧试验分数作正式混排。

将靶点标签映射到评测基因轴必须有可追溯的唯一映射，且不能事后依分数挑选；多靶点或药物标签即使恰好与某个基因名相同，也不能据此推断该基因就是生物学靶点。默认指标的精确字符串行为及未命中情况都应如实报告。

执行前置条件

至少三个有授权和真实同细胞证据的人类细胞系须同时具备 RNA、ATAC 与单细胞接触测量；不得以小鼠组织、bulk Hi-C 或不同细胞的测量替代。共享 RNA foundation 须完成，并在任何正式评测前核验训练、验证、重放与测试的跨来源暴露。

五个 Tahoe 测试细胞系的整体隔离仍是候选，原续训方案未接入该隔离；若完整消费原计划流，至少 7,562,326 条论文测试扰动来源行可能被预训练接触。这不是去重细胞数，也不是已发生的暴露计数；第一阶段和重放的跨来源暴露仍未排除。

旧 RPE1 轴的靶点覆盖风险仍是待复现预检。任何新轴都必须与共享 foundation 和所有比较方法一起审计，不能把未完成的新模型、旧试验或历史论文分数当作同协议结果。
