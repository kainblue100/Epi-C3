# 评估、挑战赛格式与已知结果

## 如何评估

1. 在观察最终留出表达之前，固定细胞、样本、目标、基因轴、模型、参数与指标。确保训练细胞、输入对照和评分参考的 ID 不相交，并保留每一步的哈希和随机种子。
2. 在相同输入对照和目标上，比较无响应对照、无先验模型、真实先验和随机先验；可同时使用训练集均值响应。超参数及效应强度只能在训练内部选择。
3. 保留模型输出、数据来源、拆分、训练配置和所有指标，包括警告及未定义值。样本标签不同不一定意味着生物学重复，基因间相关也不能替代独立样本重复。

`score` 使用 `cell-eval2==0.22.0` 的 `vcc2026` preset、默认 `pdex==0.3.0` CPU 后端，计算以下六项原始指标：

| 指标 | 含义 |
|---|---|
| `pds_cosine` | 扰动方向相似性指标 |
| `expr_mse_unbiased_capped_norm` | 以真实效应归一化的表达误差 |
| `de_wilcoxon_direction_fidelity_yield_raw` | 差异表达方向保真/产出 |
| `de_wilcoxon_direction_reach_raw` | 差异表达方向覆盖 |
| `de_wilcoxon_sig_jaccard` | 显著差异表达集合重叠 |
| `de_wilcoxon_lfc_nmae` | 差异表达 log-fold-change 归一化误差 |

具体定义和边界情况以 [cell-eval](https://github.com/ArcInstitute/cell-eval) 及其固定版本实现为准。不同平台和差异表达后端可能产生不同结果。`null` 表示不可定义，不等于零；表达归一化分母非正时不能解释该指标。`expr_mse_unbiased_capped` 等未归一化诊断并非上述六项计分指标。

本地 `score --calibrate` 使用本地留出参考构造锚点，**不是**主办方私有锚点，也不是官方排行榜成绩。`export-vcc` 和 `export-shared-vcc` 要求真实的挑战赛基因顺序、目标、上下文和控制文件；格式候选仍须用主办方工具验证。合成格式测试不代表真实提交通过，也不产生官方分数。

## HCT116 样本和目标双重留出

以下为一次固定方案的本地研究结果，不是官方成绩或外部数据集验证。实验使用同一 Orion 数据集中的 80 个训练样本、29 个留出样本，96 个训练目标、24 个留出目标，4,096 个基因；留出样本提供独立预测对照。比较无先验、真实 HCT116 表观先验和仅图拓扑打乱三臂。训练内两折校准均选择 **效应强度 0**，三臂预测与无响应对照一致。

| 全部 24 个目标的本地原始指标 | 数值 |
|---|---:|
| `pds_cosine` | 0.46196 |
| `expr_mse_unbiased_capped_norm` | 1.81034 |
| `de_wilcoxon_direction_fidelity_yield_raw` | 0.10000 |
| `de_wilcoxon_direction_reach_raw` | 0.57639 |
| `de_wilcoxon_sig_jaccard` | 0.58333 |
| `de_wilcoxon_lfc_nmae` | 未定义 |

评分过程提示样本校正/跨扰动离散度方面的警告，不能仅凭某一个高数值推断预测质量。额外固定强度 1 的诊断中，无先验、真实先验和图打乱的归一化表达 MSE 分别为 3.54374、4.46377、5.63683；该诊断不是校准模型，也未证明先验总体提升。

## 外部探索性对照

[GSE224773](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE224773) 的 HCT116 bulk DDX6 knockout 与 Orion CRISPRi 使用不同研究、细胞准备和检测方式。对 4,046 个共有非目标基因，三臂因选择零强度而具有相同 log-fold-change MSE 0.15343；Pearson、Spearman 和非零方向一致性不可定义。EDC4 不在冻结基因轴上，未替代为虚假预测。单目标跨 assay 比较不能建立普遍泛化，也不是 VCC 测试。

另对 [CRUDO 研究](https://doi.org/10.1038/s41467-026-77582-1) 的靶向增强子 screen 进行描述性重叠：1,034 个候选增强子行中，排除 1 个缺少 hg38 坐标和 100 个缺少模型轴上目标/可用启动子的行，剩余 933 行；简单调整后 p 值 <0.05 的 59 行中，10 行与目标启动子 Hi-C 环重叠，其中 5 行还有所用 SP1/USF1 与 ATAC 证据。此阈值不等同论文的完整 curated enhancer 定义；目标区域经过选择，且修订分析前曾看到部分原始 p 值，不能称为盲法。结果只描述候选覆盖，不能证明边的因果性或模型准确率。
