# Epi-C3 研究图谱 · v22

这是可以离线打开的静态研究仪表盘。双击 `index.html` 即可查看；整个目录需要保持在一起。页面不依赖 CDN、在线字体、分析服务或后端，也不读取原始单细胞数据。外部资源链接只在用户主动点击时访问。

- 交互环图可切换共享 RNA 第一阶段的已处理记录、来源矩阵记录、K562 靶点划分和候选图边打乱情况；点击图例可聚焦类别。共享训练状态为 2026-11-12 17:27:54 UTC 的静态快照，涉及 1,210,610 / 8,703,689 条计划记录，不是跨来源去重细胞数。
- 新增 KHP 和 CMO 已下载计数层的完整数值审计及候选对照流。KHP 9,354 条、CMO 1,419 条候选训练对照以及各 32 条验证对照均已读取，但没有开始新的训练。KHP 排除全部 CD8T 与已有评价身份，CMO 保留一名供体；所有非对照暂不纳入。跨数据集细胞、供体和药物隔离尚未证明，来源面板可能包含全数据选基因信息。
- 14,500 次更新的检查点已保存在服务器和本地，并重复运行相同的只读遮盖重建诊断。四个来源各有 32 个固定验证细胞；已检测且被遮盖基因的 log1p(CPM 10,000) MSE 相比训练初始下降，但 Arc 和 Orion 并非供体独立。原训练和诊断的归一化使用包含被遮盖基因的完整文库量；仅可见文库的输入消融会改变潜在表征，且并非重新训练。潜在方差与小样本重建不能证明生物学泛化、扰动预测能力或训练完成。
- 共享 RNA 第一阶段仍在进行，使用 Arc、CELLxGENE 整理版 Tabula 和 Orion；Tahoe 及其他来源尚未接入，不能将当前阶段作为完整基础模型。目标靶点和已知评价细胞已受保护，但所有跨来源重复及 benchmark 留出仍须审计。
- 两条未来分支分别使用候选调控网络和严格同细胞 RNA、ATAC 与接触联合编码。GSE267117 细胞系 RNA 与 DNA 来自不同批次，不逐细胞配对；LiMCA 报告四个人源细胞系的 RNA 与接触共测，但未证实其同细胞配对 ATAC。尚未核实至少三个合格三模态细胞系。
- 新增人类三模态基因扰动响应头原型；仅有合成数据检查，尚未训练真实扰动数据。输入身份检查不证明原始配对，完整训练集须另行核验至少三个细胞系。群体均值损失支持不同数量的对照和处理细胞，要求同一测量面板，由调用方核实条件、细胞系、划分及归一化；目标从评分中排除但仍影响 CPM 分母。该均值损失不替代 cell-eval。
- 图先验的后验内部实验已从保存的群体均值独立复算全部 14,574 条测试逐靶点评分及验证强度网格；这不是从原始细胞独立重建实验。总体真实图与打乱图平均误差差异很小，且两个直接图源靶点的真实图邻居 MSE 均高于打乱图，不能据此证明图结构有效。`cell-eval 0.8.2` 结果仅来自旧 Tahoe 部分训练模型，九条件、每条件仅 5–10 个独立预测 parent，不是新模型或官方排行榜成绩。
- CHARM 的一组小鼠 mESC 样本中，RNA、QC、ATAC 和接触文件直接匹配 805 个身份。外层归档和全部 958 个内层 gzip 均通过完整性检查；本地 SHA-256 不是来源提供的独立校验。RNA 包含分数值，不能静默四舍五入；ATAC 片段与 QC 的计数口径、QC 组蛋白标签差异以及跨物种基因轴仍需核实。身份匹配不等于训练资格，也不满足至少三个细胞系的要求。
- 全量 958 个 CHARM 接触文件的 1,607,375,529 条记录按九列格式、pairs 一基坐标和 mm10 染色体长度检查，未发现这些检查覆盖的异常；其中 1,406,651,183 条来自 805 个匹配身份。全量出现两种染色体声明集合，抽查 51 个文件头发现差异为是否包含 chrY；两者的全量频率和原因尚未确定。数据生产工具的具体坐标实现、参考序列、接触唯一性、比对质量和生物学配对并未由此独立验证。
- SC-MO-GRN-DB 的 RN119 候选网络经聚合审计，共 29,298 行、26,642 个唯一有向基因对，其中 2,656 对有相反标签；冻结轴内 157 对中有 70 对相反标签，和现有 4,141 条候选边无精确有向交集。别名、原始来源、许可和冻结测试重叠尚未核实，网络未用于训练或评价，也不随网页分发。目录里的 DS010 来源为并行测量并计算整合，DS011 虽有同细胞 RNA/ATAC，其 Hi-C 来自 bulk；均不能当作已验证的同细胞三模态。
- GRN 原型监督损失现在要求对照及处理条件各自的测量掩码，只评分共同测量的非靶点基因。每个细胞至少需一个有效基因，损失按有效基因-细胞条目平均；这是数据口径修正，不是已验证的预测性能提升。
- Tahoe 第二阶段续训器支持来源记录级回放；实际续训代码已构建五个真实输入流，并对各来源首批记录做只读数值、测量掩码和游标重放检查，未进行优化更新。2026-11-12 16:39:35 UTC 的静态排队快照显示，等待器正等待第一阶段完成和释放锁；只有检查点、哈希、诊断及磁盘门控通过才会启动。该时间点尚未开始真实续训；首批预检不代表全量数据已验证，记录数平衡不等于优化步数或梯度平衡。
- Tahoe 全分片隔离审计覆盖 6,213 个已盘点的历史评价身份，发现 5,027 条评价记录符合旧训练筛选；另排除 32 条验证记录后，新读取器预计可训练 92,090,669 条记录。新读取器及独立逐身份复核已验证，但尚未接入共享训练；九条件 interim 评价的参考和输入对照在旧筛选下均为零重叠。旧单来源训练任务未修改，其他 benchmark 和跨数据集重复仍未完全核验。
- 模型表将构造时模型模块可训练参数和 flow 优化器参数分开。K562 的 Epi-C3 与 GEARS 使用 1,861 基因；KHP 的 Epi-C3、scGen 和后验适配 scVIDR 使用同一 5,000 基因 case-01。各模型的训练设置不同，这些数值不是通用架构规模或性能排名。
