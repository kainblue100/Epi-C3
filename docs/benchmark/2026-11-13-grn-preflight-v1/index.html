01 / GRAPH COVERAGE

现有图不能通过简单换靶点解决覆盖不足

两份原始来源文件的完整 SHA-256 已重新核验。按冻结方案，仅统计两个细胞系中各有至少 100 个单基因扰动细胞、且在共同基因轴上的靶点。565 个合格靶点里，仅 1 个是既有真实图的直接源节点，共 1 条源边；它属于旧图训练划分。当前 40 靶点的直接源边覆盖为零。

匹配使用区分大小写的精确基因符号，不做别名映射。图来自 K562 的非配对 bulk 证据，迁移到 RPE1 有情境差异，也不能视为已证实的因果调控。直接源边缺失不等于间接消息传递一定无效。本次是后验元数据检查，不是新的盲测划分。

完整图的对照

真实与打乱图各 4,141 条边，完整轴上的入度和出度一致；只有 1,294 条真实边被替换（31.25%）。

投影后的对照

投影到 pilot 高变基因后分别剩 626 / 650 条边；7 个节点的出度、163 个节点的入度不同，不能把它当作该轴上严格匹配度数的对照。

03 / INPUT SEMANTICS

基因轴和归一化必须一起修正

靶点与轴

2,000 个 pilot 高变基因中，1,997 个精确匹配 foundation Ensembl 轴；RPE1 测试靶点只有 5 / 28 个在 pilot 高变轴。按现有同轴索引实现，其余靶点不能直接索引；这不是对其他编码方案的否定。

原始文库与局部 panel

在 64 个训练对照中，高变基因平均占原文库 33.84%。局部 panel 与原文库归一化的逐元素平均绝对差为 0.335014；把已 log1p 矩阵误当计数再次归一化，与正确局部归一化的差为 0.281491。这些是输入诊断，不是预测分数。

04 / BOUNDARIES

下一步仍需先解决基础模型与隔离

基础模型第一阶段及重放数据的跨来源暴露尚未充分排除。独立紧界审计指出：若既定 Tahoe 续训完整消费原计划数据，至少 7,562,326 条论文测试扰动行次会被预训练接触；这不是去重细胞数，也不是断言训练已经消费完。候选五细胞系隔离尚未接入现有等待器。

最终比较需要先完成且审计共享 RNA foundation，冻结无泄漏划分与独立图来源，并在相同条件下比较 RNA-only、无效应、有效打乱图及 STATE 或同协议预测；之后使用官方 cell-eval。旧图微小的真实图与打乱图差异不构成图有效性的证据。
