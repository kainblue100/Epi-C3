01 / FROZEN EVIDENCE

从公开峰到候选边

来源与样本

冻结的官方查询包含 1,600 个 released GRCh38 IDR peak 文件和 430 个标称未扰动 K562 实验。按靶点精确 symbol / Ensembl、一致细胞系、无记录的处理或遗传修改、至少两个生物重复过滤，选出 35 个实验的 35 个 ChIP 文件；标签可包含辅因子，并非全为已验证转录因子。

校验与注释

逐文件校验官方 MD5、大小、SHA-256 和 gzip，复用并核验另一个公开 K562 ATAC 峰文件。7,090 个共同 foundation 特征中，6,939 个有无歧义的 GENCODE v44 主染色体转录本注释；排除 47 条峰顶越界的 ChIP 记录。

三重坐标重叠

对每个注释转录本，在 0-based TSS 两侧各 1,000 bp 建窗口。仅当 ChIP 峰、ATAC 峰和同一启动子窗口实际三重重叠，才建立来源基因 → 目标基因候选边；去除自环，不赋予激活或抑制符号。

独立抽查

对 25 个源基因分层抽取 50 条边，用独立实现重新计算三重重叠，50 条通过。16,899 条边有多个 ENCODE 实验支持，涉及 8 个源基因；不同实验不等于独立生物培养。

只审计汇总和抽样边；抽查通过不代表所有边均经独立复算。完整来源清单及网络在受控运行目录，页面不发布细胞身份、原始表达或网络边。

03 / NOT A BENCHMARK

这张图不解决模型评测的先决条件

K562 ChIP 与 ATAC 是不配对的 bulk 数据，不是同一单细胞的观测；元数据标注未扰动也不能证明培养物与基准细胞完全独立。RPE1 使用该图属于跨细胞系迁移；结合与开放染色质不证明因果调控。

此图是在已知 pilot 靶点划分后筛选和构建的候选，不能作为盲选图。当前 pilot 的 K562 训练包含全部 40 个同名靶点；RPE1 训练 / 验证 / 测试分别有 0 / 0 / 1 个靶点在此图有直接源边，测试仅覆盖 1 / 28，不能据此开展有说服力的图效应比较。

第一阶段与重放跨来源暴露仍未排除；既定 Tahoe 流若完整消费，独立审计下界为 7,562,326 条论文测试扰动行次，不是去重细胞。

后续需要先完成并审计共享基础模型，冻结真正独立的共同划分、统一可索引基因轴，然后与 RNA-only、无效应、多个打乱图及 STATE 或同协议预测一起使用官方 cell-eval；现有候选图不是结果优劣的证据。
