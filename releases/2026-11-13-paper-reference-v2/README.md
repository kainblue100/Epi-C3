# STATE paper reference figure

This is a figure of **authors' saved STATE results**, not a comparison of the
two new Epi-C3 models with STATE, and not an exact reproduction of Figure 2.
The original paper's Figure 2 uses ST+HVG and also includes non-STATE
baselines; this reference instead shows saved ST+HVG and ST+SE runs.

The source is the [authors' pinned benchmark snapshot](https://huggingface.co/arcinstitute/ST-HVG-Tahoe/tree/ef2f1e13966a2a8f61fb3e8d178fae2b46aad195/benchmark).
The CSVs were generated by the authors from paired perturbations with finite
scores for both representations. Our figure independently checks the
per-context means against their dataset summary, computes equally weighted
context means and population standard deviations, and retains the original
saved L1 field without claiming it is the paper's normalized score.

Parse has three shared contexts because the saved ST+SE CD4 Memory result is
missing. The paper reports four Parse splits. The saved experiments used
different recipes; their differences are descriptive, not a causal estimate
of the effect of representation. No model weights or raw cell data are
distributed here. The numerical results are derived from State Model outputs;
the [Arc State Model License](https://huggingface.co/arcinstitute/ST-HVG-Tahoe/blob/ef2f1e13966a2a8f61fb3e8d178fae2b46aad195/MODEL_LICENSE.md)
and [acceptable use policy](https://huggingface.co/arcinstitute/ST-HVG-Tahoe/blob/ef2f1e13966a2a8f61fb3e8d178fae2b46aad195/MODEL_ACCEPTABLE_USE_POLICY.md)
apply.

**Citation:** Adduri et al., *Predicting cellular responses to perturbation
across diverse contexts with State*, Cell 189, 5914–5931 (2026),
[doi:10.1016/j.cell.2026.07.052](https://doi.org/10.1016/j.cell.2026.07.052).

## Reproduce

Download `context_metrics.csv`, `dataset_metrics.csv`, and `model_index.json`
from the pinned benchmark directory above. Run with Python 3.11+ and existing
NumPy and Matplotlib installations:

```text
python render_author_reference.py \
  --contexts context_metrics.csv --datasets dataset_metrics.csv \
  --index model_index.json --output-dir OUTPUT_DIRECTORY
python -m unittest -v test_author_reference.py
```

The script checks SHA-256 hashes for all three inputs, checks the index,
matches available contexts and finite-pair counts, and refuses to overwrite an
existing generated figure. It does not recompute the authors' per-perturbation
scores from raw predictions. For that separate operation, use the authors'
linked `recompute_benchmark.py` and indexed evaluation files.

## Prospective Tahoe exposure audit

`audit_tahoe_state_exposure.py` separately checks whether the existing
scheduled foundation continuation could encounter the paper's Tahoe test
conditions. It joins the previously generated source-row counts with
downloaded sample and cell-line metadata using exact condition labels and the
pinned official split. It validates that the existing isolation audit and
metadata plan refer to the same source universe. The output contains aggregate
counts and source hashes, not cell identifiers.

The reported guaranteed minimum is a conservative set-cardinality bound:
matched test rows minus all rows outside the scheduled eligible stream,
clamped at zero. It does not identify particular overlapping cells, prove
unique-cell counts, or establish that the waiting continuation has run. The
bound applies if that stream is consumed completely; the historical exclusion
audit protects legacy identities, not the paper's split. To reproduce, supply
the five named input paths shown by `python audit_tahoe_state_exposure.py
--help` and use `python -m unittest -v test_tahoe_state_exposure.py` for
focused checks. PyArrow is required to read the existing metadata.
